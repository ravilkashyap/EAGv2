🔧 Extension Testing Guide

✅ Step 1: Load the Extension

  1. Open Chrome and go to chrome://extensions/
  2. Enable "Developer mode" (toggle in top right)
  3. Click "Load unpacked" and select the /Users/ravil/Documents/TSAI/UniRAG folder
  4. The extension should appear in your extensions list

🔑 Step 2: Configure API Key

  1. Click the extension icon in Chrome toolbar (or use Ctrl+Shift+Space)
  2. Click the "Options" link in the popup
  3. Enter your Gemini API key in the "Gemini 2.5 API Key" field
  4. Click "Save"

Note: Get your API key from Google AI Studio

🧪 Step 3: Test the Extension

  1. Click the extension icon again
  2. Type a query like "what songs have i listened to in the last 3 days"
  3. Press Enter to trigger AI response
  4. The AI section should appear with a response (if API key is configured)

⚠️ Troubleshooting

If you see empty AI responses:

  • Check that your Gemini API key is correctly configured in the options
  • Make sure the API key has the correct permissions
  • Check the browser console for error messages (F12 → Console)

If the extension doesn't load:

  • Check the browser console for JavaScript errors
  • Ensure all files are present in the extension folder
  • Try reloading the extension from chrome://extensions/

📝 Expected Behavior

  • Typing: Shows search results immediately (no AI)
  • Enter key: Triggers AI analysis and shows response
  • No API key: AI section remains hidden
  • API configured: Shows AI response based on your browsing history

🔍 Debug Information

Open browser console (F12) and look for these log messages:

  • API key present: true/false - Check if API key is loaded
  • AI will be triggered for query: ... - Confirms AI is being called
  • API response status: 200 - Confirms successful API call
